## Atividades mapeadas

1. **Acessar a plataforma**
   
   - Cadastro de aluno
   
   - Cadastro de monitor
   
   - Cadastro de administrador
   
   - Login

2. **Buscar oportunidades de aprendizado**
   
   - Buscar aulas
   
   - Filtrar aulas
   
   - Visualizar professores, disciplinas, valores e avaliações

3. **Gerenciar aulas**
   
   - Cadastrar matérias
   
   - Criar aulas
   
   - Configurar modalidade
   
   - Definir formato
   
   - Definir valor
   
   - Configurar disponibilidade
   
   - Gerenciar materiais

4. **Matricular-se e realizar pagamento**
   
   - Solicitar matrícula
   
   - Gerenciar solicitações de matrícula
   
   - Confirmar pagamento
   
   - Processar pagamento
   
   - Cancelar matrícula
   
   - Processar reembolso

5. **Participar de aulas**
   
   - Entrar por videochamada
   
   - Gravar aula
   
   - Acessar gravações
   
   - Controlar entrada de alunos atrasados
   
   - Utilizar chat
   
   - Consultar histórico de aulas ministradas
   
   - Consultar histórico de aulas assistidas

6. **Interagir e avaliar**
   
   - Avaliar professores
   
   - Avaliar alunos

7. **Denunciar e moderar**
   
   - Denunciar aula/comportamento
   
   - Efetuar reembolso
   
   - Visualizar denúncias
   
   - Analisar evidências
   
   - Registrar decisões

## Critério de MVP

O MVP foi definido com base na pergunta:

> "Qual é o mínimo necessário para que um aluno encontre um monitor, se matricule e participe de uma aula?"

A resposta foi:

**Cadastrar-se, realizar login, buscar aulas, criar ofertas de aulas (monitor), solicitar matrícula, ter a matrícula gerenciada pelo monitor, efetuar o pagamento e entrar na aula.**

A **HU014** foi incluída no MVP porque o objetivo definido exige que o aluno não apenas contrate a aula, mas consiga **participar dela**.

Funcionalidades mais avançadas, como materiais, gravações, chat, históricos, cancelamentos, reembolsos, avaliações e moderação, ficam para os incrementos seguintes.
