## Critério de MVP

O MVP foi definido com base na pergunta:

> "Qual é o mínimo necessário para que um aluno encontre um monitor, se matricule e participe de uma aula?"

A resposta foi:

**Cadastrar-se, realizar login, buscar aulas, criar ofertas de aulas (monitor), solicitar matrícula e efetuar o pagamento.**

Funcionalidades mais avançadas, como avaliações, gravações, chat, histórico e moderação, ficam para os incrementos seguintes.
